# GrowthAI Frontend - Jatis Mobile

Interactive Demo Hub untuk C-Level FMCG

## Tech Stack
- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Framer Motion

## Pages
- `/` - Landing Page dengan demo previews
- `/demos/[type]` - Interactive Demo

## Setup

```bash
cd frontend
npm install
npm run dev
```

## Deployment

Deploy ke Vercel:
```bash
vercel deploy
```

## Branding

Project ini dibuat untuk **Jatis Mobile** - Enterprise Messaging, AI & Integration Solutions untuk FMCG.
